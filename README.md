# המרתף — ניהול עסק היין

אפליקציה לאייפון (PWA) לניהול קניות, מכירות, הוצאות, מלאי, לקוחות, קרן ורווח. בנויה באותה שפת עיצוב ובאותו מבנה כמו "הכיס החודשי": קובץ `index.html` אחד, בלי תלויות, עובדת גם בלי אינטרנט.

## העלאה ל־GitHub Pages

1. ב־GitHub: **New repository**, שם למשל `hamartef`, ציבורי (Public).
2. **Add file → Upload files**, וגוררים את 7 הקבצים (את `FIREBASE.md`, `firestore.rules` ו־`README.md` לא חייבים להעלות): `index.html`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`. אחר כך **Commit changes**.
3. **Settings → Pages**: תחת Branch בוחרים `main` ותיקייה `/ (root)`, ולוחצים **Save**.
4. אחרי דקה־שתיים האתר זמין בכתובת `https://<שם-המשתמש>.github.io/hamartef/`.
5. באייפון: פותחים את הכתובת ב־**Safari**, לוחצים על כפתור השיתוף ← **הוספה למסך הבית**.

## עדכון גרסה

בכל שינוי בקבצים מעלים את המספר בשורה הראשונה של `sw.js` (למשל `cellar-v1` ← `cellar-v2`), אחרת האייפון ימשיך להציג את הגרסה הישנה.

## איך זה מחשב

- **עלות סחורה (קרן):** ממוצע משוקלל של מחירי הקנייה של כל יין. כל מכירה "מחזירה לקרן" את עלות הבקבוקים לפי הממוצע באותו רגע, והשאר הוא רווח.
- **קרן בסחורה:** כמה כסף שלכם יושב עכשיו במלאי, לפי מחיר הקנייה.
- **רווח גולמי** = מכירות פחות עלות הבקבוקים שנמכרו. **רווח נקי** = רווח גולמי פחות הוצאות.
- **תזרים:** נכנס = מכירות ששולמו (לפי תאריך התשלום). יצא = קניות סחורה והוצאות. קנייה מוציאה כסף מהקופה אבל לא מורידה רווח, כי היא עוברת לקרן.
- **קצב הגלגול:** כמה ימים המלאי יספיק לפי קצב המכירות של 90 הימים האחרונים, וכמה פעמים בשנה הקרן מסתובבת.

## חשבונות

בהגדרות ← חשבון אפשר להוסיף כמה חשבונות שרוצים (למשל "פרטי" ו"עם השותף"), לשנות להם שם ולמחוק אותם. לכל חשבון יש יינות, לקוחות, מכירות והוצאות משלו, עם אותם מסכים. כשיש יותר מחשבון אחד, שם החשבון מופיע מתחת לכותרת, ולחיצה עליו מחליפה חשבון. הגיבוי, השחזור והייצוא לאקסל הם של החשבון הפעיל.

## סנכרון בין טלפונים ושיתוף עם שותף

אפשר לחבר את האפליקציה ל־Firebase (חינם) כדי לראות את אותם נתונים בכמה טלפונים ולשתף חשבון עם שותף בזמן אמת. ההוראות המלאות ב־`FIREBASE.md`, וכללי האבטחה ב־`firestore.rules`. בלי החיבור הזה האפליקציה עובדת כמו קודם, רק בטלפון אחד.

## מלאי פתיחה

אם יש לכם כבר סחורה, רשמו אותה כ"קנייה" אחת עם המחיר ששילמתם, והוסיפו הערה "מלאי פתיחה".

## גיבוי

הנתונים נשמרים רק בטלפון. בהגדרות יש **גיבוי נתונים** (קובץ JSON), **שחזור מגיבוי** ו**ייצוא לאקסל** עם שישה גיליונות: סיכום חודשי, מכירות, קניות, הוצאות, מלאי ולקוחות.
